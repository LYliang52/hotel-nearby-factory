# 出差小助手 · 厂家周边酒店

出差前填一个目的地厂家，把「怎么去」和「附近哪些酒店值得住」一次看明白：一张地图上标出厂家位置、周围 10 km（可调）内的酒店分布、距离远近和房价，侧栏按距离/价格/品牌排好序。

- 地图定位目的地厂家，画半径圈
- 圈出范围内所有酒店，标在地图上，**编号 + 房价直接显示在标记上**
- 距离由近到远分级着色，常住品牌（希尔顿 / 假日 / 温德姆 / 全季 / 亚朵）金色高亮
- 价格区间默认 300–600，可改；预算内单独打标
- 每家酒店一键跳携程核价 / 高德详情（含电话，能直接打过去问房价）
- 查出当天实际房价后可以**补录**，会存到本地，下次还在
- 顺带算出发地 → 厂家的驾车方案和跨城火车方案
- 结果可导出 CSV

## 快速开始

**双击 `启动.cmd`** 就行。它会依次做：

1. 检查 Node.js 装没装
2. 检查高德 key —— 没有就当场让你粘贴
3. 起服务并自动打开浏览器

服务窗口会一直留着，**关掉那个窗口就停止服务**。重复双击不会起第二个进程，只会把页面打开。

第一次用如果还没有 key，页面上点「先看演示效果」可以先熟悉界面。

### 另外两个双击就能用的

| 文件 | 干嘛的 |
| --- | --- |
| `启动.cmd` | 日常使用，双击即可 |
| `体检.cmd` | 出问题时用：检查 key 各接口、跑程序自检、再测一次启动环境 |
| `改配置.cmd` | 用记事本打开 config.json（改价格区间、加常住品牌等） |

### 命令行方式（想手动跑的话）

```powershell
cd "D:\Yswork\search the hotel near factory"
node scripts/preflight.mjs          # 检查 key
node server.mjs                     # 启动，--open 会自动开浏览器
node server.mjs --port 8080         # 换端口
node server.mjs --host 0.0.0.0      # 让局域网其他设备也能访问
```

直接指定 key（跳过交互）：

```powershell
node scripts/preflight.mjs --set-key 你的32位key
```

## 关于高德 key（重要）

这个工具用的是高德**「Web服务」类型**的 key。高德的 key 按平台分类，创建后**平台类型不可修改**：

| 你拿到的错误 | 含义 | 怎么办 |
| --- | --- | --- |
| `USERKEY_PLAT_NOMATCH` / 10009 | key 有效，但平台类型不是「Web服务」 | 新建一个 key，服务平台选「Web 服务」 |
| `INVALID_USER_KEY` / 10001 | key 写错、被删或过期 | 复制时多了空格，或去控制台重新生成 |
| `INVALID_USER_IP` / 10005 | IP 白名单没放行 | 把白名单置空，或加上本机公网 IP |
| `DAILY_QUERY_OVER_LIMIT` / 10003 | 当天额度用完 | 个人 key 额度小，等第二天 |

新建 key：<https://console.amap.com> → 「应用管理」→ 新建应用 → 「添加 Key」→ 服务平台选 **Web 服务**。

> 注意区分：控制台里「Web端(JS API)」那个 key 只能画地图（浏览器里用），不能用来查酒店、地理编码这些接口，选错了就会报 10009。要选的是 **「Web 服务」**。

拿到 key 后不用手工改文件，直接双击 `启动.cmd`，它会提示你粘贴。

## 界面怎么用

1. **目的地厂家**：填公司名 / 工厂名 / 详细地址，越完整越准（「博世汽车部件（苏州）有限公司」比「博世」好）
2. **城市**：填了会把搜索限制在这个城市，减少重名误匹配
3. **出发地**：填了才会算「怎么去」
4. 点「查酒店」→ 地图上出现红色的厂家标记和蓝色半径圈，周围酒店按编号排在图上
5. 顶部三个数字：范围内酒店数 / 预算内家数 / 常住品牌家数
6. 上面四个筛选：常住品牌、预算内、有价格、含民宿
7. 点列表任意一家 → 地图飞过去、弹窗显示地址电话；点地图标记 → 列表对应高亮
8. 在携程看到实际房价后，点「补录房价」记下来，综合排序会跟着更新

如果厂家名匹配到多个地点，侧栏会出现候选列表，点一下就能切换。

### 直接用链接打开一次查询

把常用目的地存成书签，点开直接出结果：

```
http://127.0.0.1:5173/?auto=1&factory=星湖街218号&city=苏州&from=上海&radiusKm=10
```

参数：`factory`（必填）、`city`、`from`、`radiusKm`、`priceMin`、`priceMax`、`auto=1`（自动查询）。
`?demo=1` 则是看演示数据。

## 改完配置不用重启

服务每次处理请求前都会看一眼 `config.json` 的修改时间，变了就自动重新加载 —— 换 key、调价格区间、加品牌，**保存后刷新页面就生效**，不需要重启服务窗口。

## 房价怎么拿

### 一键查携程实时价（推荐）

侧栏底部有**日期栏**（入住 / 退房可改，默认明天入住），点 **「携程实时价」**：

1. 等约 50 秒（会打开一个无头 Chrome 去携程搜你厂家的地址）
2. 弹出结果，每家显示「高德酒店名 ← 携程酒店名 + **房型** + 价格 + 相似度」
3. 相似度 ≥85% 的默认勾选，点掉不对的再确认写入

**实测**（苏州星湖街 218 号，10km）：高德 40 家正经酒店 → 携程返回 95 家带价 → **匹配 27 家（67%）**，其中 24 家是 100% 精确匹配。

**价格旁边的房型必须一起看** —— 这里抓的是列表页的「起」价，也就是该酒店**最便宜那个房型**：

| 价格 | 房型 | 酒店 |
|---|---|---|
| ¥199 | 经济单人房 | IU酒店(独墅湖高教区月亮湾地铁站店) |
| ¥131 | **特价房(无窗)** | 尚客优酒店(独墅湖高教区文星广场店) |
| ¥138 | 标准大床房 | 7天连锁酒店(独墅湖高教园区文星广场店) |
| ¥364 | 大床房（小冰箱+投屏） | 全季酒店(独墅湖高教区店) |

**价格对不上时，先查日期**：同一家 IU 酒店的经济单人房，11-13（周五）抓到 ¥222，11-15（周日）抓到 ¥199。酒店价格按日期浮动很大，所以日期栏一定要填你实际出差的入住日。

**原理**：在携程列表页的搜索框里**真的输入地址**，等下拉建议、点第一个真实地点、再点「搜索」按钮，筛出周边酒店后往下滚动把懒加载的卡片拉出来，从卡片里读价格和房型。

> 这里踩过三个坑，都不是能靠拼 URL 解决的：① 页面有**两个** `#destinationInput`，必须按 placeholder「位置/品牌/酒店」找；② 下拉第一条是"你输入的原词"回显，点了没用；③ 选中候选只是把词填进框，**必须再点一次「搜索」**才真正筛选。

**限制**：

- 要登录携程一次：`node scripts/ctrip-login.mjs`（弹窗扫码）。登录态存在 `data/chrome-profile`（已加入 .gitignore）
- 一次约 50 秒；**同一地址 + 同一日期 10 分钟内再点会走缓存，秒出**（换日期会重新查）
- 只覆盖携程有数据的酒店，剩下的还是得手工
- 携程改版可能让提取失效，届时 `lib/ctrip-live.mjs` 里的选择器要跟着调
- 匹配有品牌前缀保护：两边品牌不同（桔子 vs 悦朵）会直接压分，不会凑数

### 手工核价（补充剩下的）

1. 卡片上「**携程核价**」→ 打开携程城市列表页
2. 或者点「**高德详情**」→ 有前台电话，直接打过去问
3. 拿到实价后点「**补录房价**」→ 存进 `data/prices.json`，预算筛选和综合排序立刻生效

侧栏底部的「**批量核价**」可以一次打开 5 家酒店的携程页面，省得一个个点。

没拿到价格时，用**星级标签**（五星级 / 四星级 / 三星级 / 经济型 / 公寓式酒店）作为价位参考 —— 它来自高德的 `typecode`，比瞎猜强。

界面上的对应关系：

- 标记上显示「价?」= 没拿到价格，不是酒店免费
- 顶部那个数字在没有任何价格时会变成「价格待核价」，而不是尴尬的「预算内 0 家」
- **下单前必须自己确认当日房价**，工具里的价格只用来做初筛和排序

> **携程核价链接只能定位到城市**，定位不到具体酒店 —— 携程列表页是服务端渲染，URL 只认城市和商圈，不认酒店名（九个参数名都试过，全无效）。点进去还得自己搜一下。

> **为什么不做携程自动抓取**：试过登录携程后用 CDP 驱动 Chrome 抓列表页 —— 技术上能拿到真实房价（¥185 / ¥338 / ¥428 都是真的），但携程列表按「欢迎度」返回全城热门酒店，**实测 45 家目标酒店只匹配上 1 家（2%）**，而且那条还是错的。投入产出不成正比，整套代码（约 1200 行）已删除。

> **美团 / 去哪儿已移除**：美团链接实测跳验证中心、接口 403；去哪儿给的只是首页，都定位不到具体酒店，代码里的按钮和配置都删了。

> **百度价格档位已撤销**：试过用百度 `price_section` 按价格区间筛酒店（百度的 `detail_info.price` 是人均消费不是房价，但区间筛选确实生效），坐标匹配后能覆盖约 47%。但个人 AK 的检索服务并发上限太低，**一查询就报「检索服务并发量接近上限」**，串行化之后虽然不报错但一次要等 8–10 秒，性价比不划算，已整套移除。

## 「携程核价」链接怎么定位到城市

携程酒店列表必须带 `city=<数字 id>` 才会按城市展示，这个 id 和高德的 citycode 不是一个体系。`scripts/build-ctrip-citymap.mjs` 用探测列表页标题的方式反查了一份映射，缓存在 `data/ctrip-city-map.json`（已含 583 个城市，常见出差城市都覆盖了）。

如果某个城市不在缓存里，核价按钮会退化成关键词搜索链接。补齐方式：

```powershell
node scripts/build-ctrip-citymap.mjs --from 700 --max 1200
```

## 打分规则

综合分（满分 100）＝ 距离 40 ＋ 品牌 35 ＋ 价格 20 ＋ 口碑 5

- 距离：线性衰减，贴边为 0
- 品牌：常住品牌 35 / 同档连锁 22 / 经济型 10 / 非连锁 0
- 价格：落在区间内 20，低于下限 14，超上限按超出幅度降到 2
- 口碑：高德评分 ÷ 5 × 5

品牌清单、档次分级都在 `config.json` 的 `brands` 里，想加自己的常住品牌直接往里加关键词即可。

## 常见问题

**搜不到我填的厂家**
加城市名，或换成详细地址（「XX 路 XX 号」）。实在不行用地图坐标搜索：直接在浏览器里打开高德地图找到该厂，把坐标填进 `factoryLng` / `factoryLat`（用 curl 或 Postman 调 `POST /api/plan` 时支持这两个字段）。

**酒店比预期少**
高德周边搜索按距离返回最近的若干家，默认取 4 页（100 家）。可在 `config.json` 把 `defaults.maxPages` 调大（上限 10 页），或缩小半径让近处的酒店不被挤掉。

**地图打不开 / 底图空白**
底图用的是高德公开瓦片和 unpkg 上的 Leaflet，都需要联网。公司网络如果拦了，可以把 Leaflet 换成内网镜像。

**端口被占用**
`node server.mjs --port 5174`
